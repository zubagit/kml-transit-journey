# License choice for the owner

**Recommended: MIT.** It lets people use, modify, redistribute, and sell the app while retaining the copyright and license notice. This fits a small community tool with minimal reuse restrictions. A proposed MIT LICENSE and matching package metadata are prepared locally. Confirm this choice and your preferred copyright name before publishing.

| Choice | Main reason to choose it |
| --- | --- |
| MIT | Simple permissive reuse, including commercial reuse. |
| Apache-2.0 | Permissive reuse with express patent provisions and more notice requirements. |
| GPL-3.0 | Require distributed derivative software to remain under GPL terms with source obligations. |

Compare the full terms: https://choosealicense.com/licenses/ . If choosing another license, replace LICENSE and update `package.json`, the source check, README, and release notes together. Public visibility alone does not make software open source.

Only license material you have the right to distribute. Confirm ownership or permission for the included fictional network. External map imagery, OSM data, and imported KML keep their separate terms. The current copyright label is the project's contributor name, not a claim about the user's legal identity.
