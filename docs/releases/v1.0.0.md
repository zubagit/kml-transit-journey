# KML Transit Journey v1.0.0

Private draft of the first Windows desktop release, based on the supplied v25-era KML Transit Journey starter app. The supplied HTML has no explicit internal v25 version marker. Public distribution is awaiting owner approval.

## Features

- Fictional Calgary Rapid Transit sample network and KML import.
- Station-to-station journey planning with transfer directions and simulated travel times.
- Address suggestions and door-to-door planning using online geocoding and pedestrian routing.
- Manual line service modes, speeds, frequencies and dwell times; Metro defaults.
- Light/dark themes, map selection and origin/destination swapping.
- Bundled Leaflet, isolated Electron renderer, and Windows x64 NSIS installer setup.

## Download

Choose `KML-Transit-Journey-1.0.0-Windows-x64-Setup.exe`. `SHA256SUMS.txt` lists asset hashes. Source ZIP/TAR downloads contain source code, not an installer. There is no automatic updater.

## Known limitations

- Unsigned installer; Windows may show an unknown-publisher warning.
- Internet required for background tiles, address lookup and pedestrian routing.
- Public demo services may throttle, change or become unavailable; production usage rights and scale have not been established.
- Walking legs become approximate when routing fails. Times are simulated rather than real transit schedules.
- KML requires track LineStrings and nearby station Points, up to 15 MB; KMZ is unsupported.
- Imported networks and service adjustments are not saved between sessions.
- Windows x64 only; ARM64 and 32-bit builds are not supplied.
